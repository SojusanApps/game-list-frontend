# CHANGELOG

> Date format is DD.MM.YYYY.

## v. [1.3.0] - 30.10.2026

**Compatible backend version: [6.1.0]**

- Game import: filling the list from a store now also reads each game's store id. Games GameList already knows are added to your list straight away (as Plan to Play, marked as owned on that store unless they are only on the wishlist; a game already on your list just gets the store added to where you own it), and only the games it could not recognise are listed, with their store and store id, for you to match against the catalogue. The import page no longer has a free-text titles box: the list is filled only by the store buttons, and single entries can be removed before matching. Your matches are remembered as suggestions for those store games, so the next sync recognises them for you, and an admin can approve them for everyone. The extension must be up to date (version 1.1.0 or newer); otherwise the page asks you to update it.
- Admin panel: new "Store Mappings" page to review the matches users made between store games and catalogue games (accept or reject, with filters), and a form to add a mapping by hand. The form can also mark a store item as "not a game" (a soundtrack, for example), so the import skips it. On the import page, unmatched titles can be marked "Not a game" too; the admin then confirms it for everyone. Games already on your list can now be picked in the match step too: the store id is matched to the game and only the store is added to its "owned on" (nothing else of the entry changes).
- Game import: every step after the store buttons now shows where each game came from — the shop logo, the shop name and the store id, as on the first page. This applies to the matching step (under each title), the duplicates step (under each title that resolved to the same game) and the "configure the games to import" table (under each game).
- Game import: the "Match" and "Resolve" steps are now one "Match" step. All titles are listed on the left; pick one and search the whole catalogue on the right, with the same filters as the Search Engine (the search starts with the title, the filters reset for each title). After a pick the next unmatched title opens. "Not a game" is available for every title. The list of titles can be hidden to give the search the full width. Titles are no longer sent to the backend for suggestions.
- Search filters: new "IGDB ID" filter to find a game by its exact IGDB id. It is available in the Search Engine (and in its URL, for example `/search?igdb_id=1942`), on the import Match step and in the game picker of the admin "Store Mappings" page; it is not shown on a user's game list, which cannot filter by it.
- Admin panel: on the "Store Mappings" page the game field of the "add a mapping" form now opens a window with the search and all the game filters, instead of a plain dropdown. Each mapping shows the store logo in its store badge, and who submitted it as an avatar with the nickname, as on the other admin pages.
- Search filters: the Publisher and Developer filters now show the selected company again after the filters are reopened, and clearing one no longer fails with "Invalid input: expected string, received null".
- Shortened text: whenever a name is cut off with "…" (game titles in the search box, list rows, the compare table, rankings, tier lists and the import steps; collection names; usernames; notifications; your latest list update), hovering it now shows the full text in a tooltip. The tooltip appears only when the text is actually cut off, and replaces the plain browser tooltips that a few of these places had.
- Contrast and colors: buttons, active tabs and badges now meet the WCAG AA contrast ratio in both themes (dark labels on the neon dark-mode buttons, darker fills in light mode), and secondary ("dimmed") text is darker. Dark mode now has one brand color everywhere (light buttons and badges no longer get a dark indigo background next to cyan elements), and dialogs and menus use the same dark surface as the pages. "Cancel" is now an outlined button in every dialog instead of a loud filled one. Scores keep one color per value in both themes: the review score, "Undecided" and the score card on the game page use the same red / yellow / green as the covers. On the game page the Ranked and Popularity cards are blue and purple, so they never look like a green score.
- Keyboard and screen readers: game covers show a clear focus ring, the quick-actions button on your own list and the delete button in collections appear when a cover is focused (and are always visible on touch screens), and the poster title is no longer enlarged on hover. Icon-only buttons (mobile menu, calendar arrows, remove game, move up/down in rankings, notifications, filter chips) now have names, the ranking drag handle is no longer a stray tab stop, and information that was only in hover tooltips (gender, platforms, tier notes, recommendation counts) is available without a mouse. Buttons are no longer nested inside links, "Not a game" and "Remove pick" in the import are real buttons, the header search announces its suggestions and the highlighted one, filter groups announce what is selected, and after opening another page the focus moves into it and the page title is announced. Form fields that had only a placeholder now have labels, and the review and note counters are read with their field. Home page carousels no longer move on their own, and their buttons are translated.
- Deleting is always confirmed: removing a game from your list, deleting your review, deleting a collection, marking all notifications as read and deleting notifications each ask first. New: a collection's owner can delete it from the edit window ("Delete collection" shows the collection's name and how many games are in it). Moving games in a tier list or a ranking no longer shows a success message every time (only failures are reported).
- Errors: a page that failed to load because of a network or server problem now shows "Couldn't load this page" with "Try again" and "Go home", instead of "404 Not found" (a game, profile or collection that really does not exist still shows 404). Lists, search, the collections and the release calendar show the same error box with a "Try again" button, and never "No results" together with an error.
- Signing in: opening a page that needs an account (Import, Notifications, Settings, the admin pages) while signed out now shows the sign-in prompt and brings you back to that page afterwards, instead of silently sending you to the home page. The prompt now says what you were trying to do (add the game to your list, follow it, write a review, favorite a collection, send a friend request). The site no longer waits for the login service before showing anything: if it cannot be reached, you can still browse, and a dismissible banner says that signing in is unavailable.
- Navigation: the current section is highlighted in the top bar, the burger menu now also lists Notifications, Profile, Settings and FAQ, the bottom bar and the burger menu switch at the same width (so there is no width where a signed-in user has neither), and signed-out visitors get a bottom bar with Home, Search, Calendar and Sign in.
- Address and Back button: the status, sort, filters, search text and page of your game list, the filters and page of collections, notifications, friends, reviews and a collection's games, and the view, week/month and date of the release calendar are now part of the address. Going back from a game restores your filtered list, the pages can be shared, and changing the page scrolls back to the top of the list. Search shows its active filters as removable chips with "Clear all", the filter window has a "Reset" button, and switching the search category tells you that game filters were cleared. The collections filters are shown directly (no collapsed panel), the "Create collection" button moved above them, and the "Type" label of the All / Favorites switch is now "Show". The release year filters are now "Released from (year)" and "Released until (year)" and accept the same year in both (a single year); previously the dates were also sent one day early in some time zones.
- Phones: the release calendar shows a list of days with releases instead of a seven-column grid, the add/edit windows are full-screen with smaller padding, their fields stack, the import rows wrap, the profile statistics stack, notifications are a list of cards (with their category and level), and the compare table keeps the game column in view while scrolling sideways. The "+ more" and "See all" on a calendar day show only when the day has more games than fit.
- Notes: a note on your list entry can now be seen by other users (it was already hidden for moderated notes and banned authors): a note icon on the game cover opens it, there is a "Note" column in the table, and other users can report it. The edit window says that others can see the note.
- Notifications: a release notification opens the game, friend-request notifications have Accept and Decline buttons right in the bell and on the page, and the bell has "Mark all as read". The bell's label includes the number of unread notifications.
- Import: leaving the import page while matching titles asks for confirmation (and the browser warns before closing or refreshing), because the matches are not saved.
- Visual consistency: every score uses the same chip and one decimal for averages, empty states, error boxes, stat cards, panel headers and pill labels are shared components, pages have the same width and spacing, information labels are at least 12 px and in sentence case, and the collection page's games sit on the same panel as other lists (it used styles that did nothing). The game information panel no longer cuts words in the middle and hides fields that have no value.
- Smaller changes: the theme switcher now has a "System" option (the default for new visitors) and both switchers show their name on hover and have the same size; changing the language no longer reloads data that does not depend on it; the sort and developer filters no longer show a clear (X) button when empty; the Related games section shows up to five bigger covers per row, sized to the number of rows; the company page opens the section that has games; the screenshot viewer shows "3 / 12" and can be swiped; reviewer names link to their profile; the scroll-to-top button appears after about half a screen; hard-coded English texts (missing image, collection cards, import errors, image descriptions, page description) are now translated, and a test fails when a new one is added; every tooltip is now the same one, instead of some being the browser's.

## v. [1.2.0] - 22.10.2026

**Compatible backend version: [6.0.0]**

- Game import: the Steam profile import was removed, together with the "Select Import Source" step — the Import page now opens directly on the title import. Instead, above the titles box there is a new "Fill from a store" row with Steam, Epic Games, PlayStation, Nintendo and GOG buttons. They use the new GameList browser extension to read the library of the store you are already logged in to in your browser and add its titles to the list for you, so no public Steam profile is needed anymore and more stores are covered. You then match the titles against the catalogue as usual. If you are not logged in to that store you get a link to its login page, if reading the library fails you get a message naming the store, and if the extension is not installed you are offered it on the Chrome Web Store and Firefox Add-ons. The titles box now has line numbers.
- Search engines: the site is now much easier for Google to discover and understand. Added a `robots.txt` and a sitemap (generated by the backend) listing the home page, games, companies, public collections and public profiles. Every page now declares its canonical address, so filtered or paged variants such as `/search?...` are not treated as duplicates. Private pages (settings, notifications, import, the admin pages, list comparison and the "not found" page) are marked as not to be indexed. Link previews now use an absolute 1200×630 PNG image instead of a relative SVG, and game pages use the game's cover.
- Home page: added a heading and a short introduction above the carousels, and a clearer page title and description ("Track, rate and discover games") in both English and Polish, instead of just "Home".
- Structured data: the home page now declares the site and its search, and game pages declare the game (title, summary, cover, release date, genres, platforms, developer and publisher), which lets search engines show richer results.

## v. [1.1.0] - 24.09.2026

**Compatible backend version: [5.4.0]**

- Game List page: entries are now sorted by title (A–Z) by default, and the filter panel has a new "Sort Results By" field as its first field. You can sort by title (A–Z or Z–A) or by your score (high to low or low to high); entries without a score always come last when sorting by score. The sort applies to both the grid and the table, and also to the results when you search by title (they are no longer ordered by best match). It resets to title A–Z when you reload the page.
- Grid views: the grid now fills the whole box around it instead of stopping partway and leaving empty space (and clipping the cards) below it. This applies to your game list, search results, collections, a collection's games, and your friends. The box height now follows the window height (between 500 and 850 px), and the space between rows of game covers now matches the space between columns.
- Collection page: in collaborative mode, the "BY" / "PRZEZ" label on the "added by" badge is no longer larger than the username next to it.
- Collections: favorites are now personal. Each user has their own favorites, so a collection you favorite is no longer shown as a favorite to anyone else, and a collection's owner no longer decides it for everyone. You can favorite any collection you can see, not just your own, using the heart on the collection card, in the table row, or next to the title on the collection page (signed-out visitors are asked to log in). The "Mark as Favorite" checkbox is gone from the create/edit collection window. The favorites filter on the collections list is now called "My favorites" and shows the collections you have favorited; on your own profile that includes collections owned by other people, while on someone else's profile it shows only their collections that you have favorited. It is hidden when you are not logged in. Collections that were favorited before stay favorited for their owners only.
- Game page: the "Add to Collection" window now also lists collections shared with you (collaborative collections you were added to as a collaborator), not just your own. Shared ones are marked with a "Shared" badge and show who owns them, so they are easy to tell apart from your own collections.
- Game covers: the score chip in the corner of a cover is no longer shown when the game has no score yet (a score of 0), instead of showing a red "0.0".
- Game import: the "configure the games to import" step (Steam and Title import) now lets you sort by Title, Status or Score — click a column header to sort ascending, click again for descending, and a third click returns to the original order. Games without a score always sort last, and editing a row while sorted does not move it until you re-sort. You can also set the status for every game at once (handy if most of what you imported is already completed) using the new "Set status for all games" control above the table, then adjust individual games afterward.
- New game list status: "Not Planned", for games you own but don't intend to play. It appears everywhere the other statuses do — the status dropdown, list and table badges, the import flow, the FAQ, and your profile's status breakdown.
- Game List page: the status filter is now a single dropdown instead of a row of buttons that could wrap onto multiple lines.
- Reviews now have a language (English or Polish). The review window first asks which language you are writing in — there is no default, so you always choose — and only then shows the recommendation and text fields. A chip on the second step shows the chosen language and takes you back to change it without losing what you typed; when you edit an existing review it opens straight on the text, with the same chip. Each review shows an EN / PL badge. The game page's review preview and the Reviews page have a new English / Polish / All filter, which starts on your interface language (or All if it is neither); on the Reviews page the choice is kept in the address, so a filtered list can be shared, and "View all reviews" carries your choice over. Your own review always stays at the top, whatever the filter. Language names are shown in the language of the interface.
- Game list: editing or removing a game on your list now shows up immediately. The window closes as soon as you click Save or Remove, and your list and the game page update right away instead of after a reload. If you're viewing one status (for example Playing) and change a game to another, it leaves that view at once; a changed score is re-sorted a moment later. If saving fails, the change is undone, an error names the game, and reopening the window brings back what you typed. The "Updated" and "Removed" messages are gone, since the change is visible on its own.
- Error messages now appear in your interface language. When the server can't be reached or doesn't explain what went wrong, you get a message in English or Polish that says what kind of problem it was (no connection, not logged in, no permission, not found, too many requests, or a server problem) instead of an English message such as "Error fetching game list" or "Internal Server Error". Validation errors shown in a pop-up no longer start with internal field names such as "owned_on:".
- Updated dependencies, including Pragmatic drag and drop to version 4. The drag-and-drop code in rankings and tier lists now uses the library's new import paths, because version 4 removed the old ones.

## v. [1.0.0] - 02.09.2026

**Compatible backend version: [5.3.3]**

- Result lists can now be viewed as a paginated table instead of the infinite-scroll grid. A toggle (grid / table icons) switches between them, and the choice is remembered across sessions and applies everywhere it is offered: search results, your game list, collections, a collection's games, the release calendar list and day pop-up, a company's developed/published games, a game's related titles, and your friends. The table shows First / Previous / numbered pages / Next, plus a "go to page" box when there are many pages; on search, the page number is part of the URL so paged links can be shared and the back button steps through pages.
- Game List page: the separate list view was removed — it is now grid or table.
- Notifications, Admin Reports, Admin Translation Suggestions and Game Reviews now use the same pager; Game Reviews previously mis-counted its pages and could land on an empty page.
- Title import: added the release date to the CandidateCard for easier identification of the game.
- Game import: the "configure the games to import" step (Steam and Title import) no longer lags while typing — rows are virtualized and only the row being edited re-renders.
- Modal forms now keep what you have typed when the dialog is closed — by an accidental click outside, Escape, or Cancel. The draft is restored the next time you open the dialog and is only cleared after a successful save. Covers game reviews, game list entries, translation suggestions, collection create/edit, add-to-collection, ranking and tier-list descriptions, reports, and the staff warn/ban actions.
- Collection collaborator picker: search results and selected collaborators now show the user's avatar, already-added collaborators are marked with a check icon, the dropdown no longer disappears behind the dialog buttons, and search now filters by the collaborator's username.
- Game list dialog: fixed the "started"/"completed" date fields, and playtime is now entered and displayed in hours while still being stored in minutes.
- Gaming background graphic: the close icon no longer looks like a plus sign.
- Polish translations reworded to be gender-neutral.
- Added the common layout for modals.
- Emoji and text-character icons were replaced with monochrome SVG icons everywhere they were used — game list status labels, empty-state and info graphics, the Steam "not found" warning, collection filters, the ranking screens, and the back/continue arrows in the import flows.
- Game list status now shows a coloured icon consistently across the app: the list, the compare table, the profile statistics and recent-activity, the add/edit dialog (the icon now also shows in the status field itself, not only in the dropdown), and the import "configure games" step.
- Collections list: the type filter uses a filled yellow folder ("All") and a filled red heart ("Favorites").
- Collection and collections pages: an empty collection or an empty result set no longer shows two "nothing here" messages at once.
- Pairwise ranking button now uses an icon instead of an emoji.
